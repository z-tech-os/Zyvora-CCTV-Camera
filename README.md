# 📡 Zyvora CCTV AI Camera

A browser-based AI CCTV and security monitoring project developed under the **Zyvora** brand.

Zyvora CCTV AI Camera allows a phone to work as an AI-powered camera while a laptop can act as the monitoring station. The system uses browser technologies to establish the connection and perform local AI-based object detection.

## 🌐 Live Website

https://z-tech-os.github.io/Zyvora-CCTV-Camera/

## 🧠 Main Features

* 📱 Phone AI camera
* 💻 Laptop CCTV viewer
* 🧠 Local AI object detection
* 📡 Phone-to-laptop live video streaming
* 🔗 Peer-to-peer browser connection
* 📷 QR code connection support
* 🖼️ Picture-in-Picture monitoring
* 🚨 Person detection alerts
* 🔊 Alert sound
* 🌑 Black-screen monitoring mode
* 📱 Responsive design
* 🌐 Works directly in a modern web browser
* 💰 No traditional server required for the basic system

## 🛠️ Technologies

This project uses:

* HTML5
* CSS3
* JavaScript
* WebRTC
* PeerJS
* TensorFlow.js
* COCO-SSD
* QRCode.js

## 🔐 Local AI

The AI detection component uses TensorFlow.js and COCO-SSD directly in the browser.

This allows object detection to be performed locally on the device instead of sending camera frames to a traditional AI server.

## 📱 How It Works

### 1. Start the Laptop

Open the website on the laptop and select:

**💻 I AM LAPTOP**

The system generates an identification code and QR connection information.

### 2. Start the Phone

Open the same website on the phone and select:

**📱 I AM PHONE (AI Camera)**

Allow the browser to access the phone's camera.

### 3. Connect the Devices

Use the laptop identification information to connect the phone camera to the laptop viewer.

### 4. Monitor

The laptop can display the live camera stream while the AI system monitors the camera feed for detected people.
